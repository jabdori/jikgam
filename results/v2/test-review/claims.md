# T5b: 사람 확인 일치율 독립 재계산(GLM-5.3)

- 대상: 표본 data/v2/local/review/claims_test_sample.json, 사용자 결과 claims_test_result.json, 적용 요약 results/v2/test/claim-check.json, report.json. 저장소 함수는 쓰지 않고 직접 계산했다.
- 산출물에는 수치와 sample_id만 남긴다(주장 글은 옮기지 않는다).

## 연결 검증

- sample_digest: 표본·결과·요약·재계산이 모두 같은 값(8d372a16b9553c96…)이다 → True.
- 짝지음: 표본 30개, 결과 30개, id 집합 일치 True, 모두 확인 완료 True, 라벨 형식 유효 True.
- 입력 파일 sha256(답변·단계 기록 4개): 재계산·표본·요약 모두 일치 → True.
- 주장 결합: 30개 모두 (실행, 행, 주장 순서) 위치의 주장 sha256·판정 모델 라벨과 일치 → True(불일치 0개).
