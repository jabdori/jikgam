# 화면 시안

고객사 SaaS와 내부 관리 콘솔의 화면 시안이다. 정적 HTML이며, 디자인 도구 전용 태그(`<x-dc>`, `<sc-for>`, `<sc-if>`)와 화면에 들어갈 값을 만드는 `renderVals()` 스크립트가 들어 있다. 브라우저에서 바로 열리지는 않는다. 레이아웃과 정보 구성의 참고용으로만 쓰고, 숫자는 실제 결과 파일에서 읽는다.

| 파일 | 콘솔 | 화면 |
|---|---|---|
| Main.dc.html | 고객사 SaaS | 실시간 통화 |
| Compare.dc.html | 고객사 SaaS | 통화 기록 |
| Report.dc.html | 고객사 SaaS | 운영 리포트 |
| Knowledge.dc.html | 고객사 SaaS | 지식·정책 |
| Integrations.dc.html | 고객사 SaaS | 연동 |
| Quality.dc.html | 관리 콘솔 | 모델·벤치마크 |
| Trace.dc.html | 관리 콘솔 | 통화 리플레이 |
| Tenants.dc.html | 관리 콘솔 | 고객사 관리 |
