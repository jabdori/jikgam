# 공용 컴포넌트

> 처음 읽는다면: [디자인 하네스](README.md) · [ADR 0022](../adr/0022-디자인-하네스.md)

화면 코드(`jikgam/web/saas/`, `jikgam/web/admin/`)는 이 컴포넌트와 숫자 형식(`jikgam/web/ui/fmt.py`)만 써서 화면을 만든다.

- 구현: `jikgam/web/ui/components.py`
- 모양: `jikgam/web/static/components.css`(토큰만 쓴다)

새 모양이 필요하면 컴포넌트를 더하고 아래 표에 이유를 적는다.

## 기본 컴포넌트(지시에 정한 일곱 가지)

| 컴포넌트 | 쓰는 곳 |
|---|---|
| `shell` | 모든 화면의 문서, 메뉴, 상단바(검색 또는 경로 표시), 본문 건너뛰기 링크. `theme`으로 고객사·관리 테마를 고른다 |
| `card` | 테두리 있는 묶음. 제목·보조 글자·오른쪽 글자·버튼 자리가 있고, `flush`면 표를 꽉 채운다 |
| `table` (`Col`, `Row`) | 첫 칸이 행 제목인 표. 줄 링크, 고른 줄, 숫자 칸, 좁은 화면에서 숨길 칸이 있다 |
| `badge` | 처리 결과, 판정, 상태. 색은 `neutral`·`muted`·`accent`·`positive`·`caution`·`negative` 여섯 가지 |
| `metric` | 지표 칸(이름, 값, 보조 글자) |
| `empty` | 빈 상태 |
| `drawer` | 목록 옆 상세. 열리면 제목으로 포커스가 가고 Escape나 닫기로 닫힌다 |

## 더한 컴포넌트

| 컴포넌트 | 더한 이유 |
|---|---|
| `stack`, `row`, `grid`, `columns`, `split`, `spacer`, `anchor` | 배치. 화면 코드가 HTML을 직접 쓰지 않게 하려면 배치도 컴포넌트여야 한다 |
| `text`, `para`, `code`, `link`, `heading`, `subheading`, `sr_only`, `joined` | 글자. 색·크기·고정폭을 토큰 클래스로만 고르게 한다 |
| `notice` | 눈에 띄게 둘 짧은 안내(데모 자료, 예상 비용, 경고) |
| `button`, `chips` (`Chip`) | 시안의 버튼과 필터 칩, 기간 고르기 |
| `page_header`, `pane_head` | 화면 제목 줄과 세로 목록의 제목. 한 화면에 h1이 둘 생기지 않게 낮출 수 있다 |
| `keyvals`, `tags`, `ordered`, `link_list` | 고객 정보·설정 값, 짧은 꼬리표, 약관 조항의 항, 안내 근거 조항 링크 |
| `steps` (`Step`) | 실시간 통화의 진행 단계, 통화 기록의 처리 내역, 지식·정책의 처리 단계 |
| `disclosure` | 다 끝난 처리 단계처럼 평소에 볼 일이 적은 내용을 한 줄로 접는다(지식·정책 리뷰 지적 2) |
| `bar`, `bar_list`, `stack_bar` (`Part`) | 운영 리포트의 사유별 건수와 처리 결과 비율 |
| `conversation` (`Turn`, `Divider`, `Reveal`) | 대화와 그 사이의 "요청 변경" 한 줄, 녹음 위치에 맞춘 강조, 말 아래 근거 조항. 줄 이름(`key`)으로 갱신 때 이미 있는 줄을 그대로 둔다. 실시간 통화에서는 따로 스크롤되는 영역(`follow`)과 시계(`now_ms`, `running`)를 두고, 말하는 중인 답(`Reveal`)은 기록된 재생 시각에 맞춰 글자를 차례로 드러낸다 |
| `item_list` (`ListItem`) | 진행 중인 통화 목록, 고객사 고르기(가로 카드) |
| `player`, `listen_source`, `toggle` | 녹음 재생(다시 듣기는 기본 컨트롤, 리플레이는 재생 버튼), 실시간 통화의 통화 듣기, 판단 시점마다 멈춤 |
| `live`, `slot` | 실시간 통화의 갱신. 서버가 만든 문서를 다시 받아 지정한 영역에서 바뀐 부분만 맞춘다(JS는 글자를 만들지 않는다). 이미 있는 요소는 그대로 두므로 상태 색이 CSS 전환으로 바뀐다 |
| `swap` | 같은 화면의 다른 상태로 가는 링크(리플레이의 이전·다음 판단)를 누르면 문서를 새로 열지 않고 이 영역만 바꾼다. 이름(`data-key`)이 같은 순위 행은 새 자리로 옮겨 가고 막대는 새 길이로 바뀐다 |
| `lanes` (`Lane`, `Seg`, `Mark`), `playlist` (`PlayItem`) | 통화 리플레이의 재생 띠(화자별 구간, 판단 표시, 끼어들기, 지금 위치)와 재생 목록 |
| `rank_bars` (`RankRow`, 행 이름 `key`), `heatmap` (`HeatCell`), `version_block` | 통화 리플레이의 조항 순위와 직전 대비 변화, 조항 × 판단 순위 표, 무효가 된 답과 새 답 |
| `check_list` | 고객사 관리의 온보딩 체크 |
| `form`, `field_text`, `field_select`, `field_checks`, `hidden` | 모델 추가와 벤치마크 실행 폼. `field_text(show_for=…)`는 어댑터에 필요한 칸만 보인다 |
| `field_file`, `form(multipart=True)` | PDF를 표준 파일 입력으로 고르고 전송한다. 파일 입력에도 연결된 레이블을 둔다 |
| `preformatted` | 구간 원문의 줄바꿈을 보존한다. 좁은 화면에서는 긴 줄을 감싸 가로 넘침을 막는다 |
| `field_choices` | 연결되지 않은 로컬 모델을 선택 불가로 표시한다. 서버 쪽에서도 같은 조건을 검사한다 |

지식·정책의 상단 검색은 `shell(search_fields=…)`로 고른 문서를 유지한다. 새 처리와 검색 비교는 기존 카드·표·접기 컴포넌트를 사용한다.

독립 리뷰 후 보완:

- `keyvals(narrative=True)`는 구간 정보처럼 긴 설명을 라벨 아래에 왼쪽 정렬한다. 기본 금액·숫자 키·값 배치는 유지한다.
- `responsive(wide, narrow)`는 넓은 검색 비교 표와 모바일 핵심 지표 표 중 하나만 보인다. 모바일은 단일 근거 재현율을 기본으로, 지연·오류·추가 지표를 행별로 펼친다.
- 지식·정책의 선택한 문서는 같은 목록의 선택 행과 문서명·처리 단계·구간 상세로 이어진다. 완료 단계와 기존 게시 설정은 `disclosure`로 접는다. 업로드 진입점은 제목 옆에 둔다.
- 검색 비교·비용 확인·모델 선택·실행 상태는 한 카드에 묶고, 판별·상담·음성·부하 및 모델 등록은 이름 붙인 별도 접기 영역에 둔다.
- 검색 고정 test 표와 `val 실행 결과` 표는 같은 반응형 표 컴포넌트를 각각 사용한다. val 영역은 같은 구성의 val 기준 행과 완료된 화면 실행을 함께 표시하고, 실행 결과가 없으면 `empty`만 보인다.

## 움직임(2026-10-19)

시간과 곡선은 `tokens.css`의 `--motion-*`, `--ease-*` 토큰만 쓴다. CSS와 `console.js` 모두 같은 토큰을 읽는다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--motion-fast` | 120ms | 색·배경 상태 변화, 마우스 올림 |
| `--motion-base` | 200ms | 새 대화 줄 나타남, 단계·근거 색 |
| `--motion-slow` | 320ms | 순위 행 이동, 막대 길이, 재생 위치 선 |
| `--motion-char` | 90ms | 말하는 중인 답의 글자 하나 |
| `--motion-emphasis` | 1400ms | 처음 나타난 "요청 변경" 구분선 강조(한 번), 지금 단계 고리 |
| `--motion-pulse` | 1600ms | 말하는 중·응대 중 점의 깜빡임 |

- 곡선은 `--ease-standard`, `--ease-enter`, `--ease-exit`다.
- 움직임 줄이기 설정(`prefers-reduced-motion: reduce`)이면 토큰이 0이 되고, 애니메이션·전환을 모두 끈다. `console.js`도 행 이동과 부드러운 스크롤을 하지 않는다.
- 말하는 중인 답의 글자 공개는 장식이 아니라 "지금까지 말한 내용"이어서 움직임 줄이기에서도 시각에 맞춰 드러나되 서서히 나타나지 않는다.
- 스크립트가 붙이는 클래스는 `c-` 접두어(`c-enter`)이고, 갱신 때 서버 내용으로 지우지 않는다.
