# 고객사 화면 금지어

> 처음 읽는다면: [전체 흐름 안내](../overview.md) · [용어집](../glossary.md)

고객사 콘솔(`/app/` 아래 모든 화면)은 상담 운영팀이 보는 화면이다. 엔진 내부 용어와 수치가 나오면 안 된다(ADR 0021, 0022). 아래 표의 낱말이 화면에 나오면 검사가 실패한다.

- `tests/test_saas_terms.py`: 테스트 자료로 렌더링한 HTML을 검사한다.
- `scripts/ui_check.py`: 실제 결과로 띄운 화면을 브라우저에서 검사한다.

두 검사 모두 이 표를 직접 읽는다. 낱말을 더하거나 뺄 때는 이 표만 고친다. 관리 콘솔(`/admin/`)에는 적용하지 않는다.

## 맞추는 방식

- **부분:** 그 글자가 어디에든 들어 있으면 걸린다. 한국어 낱말에 쓴다.
- **낱말:** 앞뒤에 영문자가 붙지 않은 경우만 걸린다. 숫자와 한글은 붙어도 걸린다(`233ms`, `Jev가`). 대소문자는 가리지 않는다. 영어 약어에 쓴다(`ms`는 `items` 안에서는 걸리지 않는다).
- **정규식:** 표에 적은 패턴(Python `re`, 대소문자 무시)으로 찾는다.

검사 대상은 보이는 글자와 사용자에게 보이는 속성(`title`, `aria-label`, `placeholder`, `alt`, `value`)이다.

## 설정에서 더하는 낱말

`config/decision_models.toml`과 `config/decision_models.d/*.toml`의 `model` 값, `config/voice.toml`의 `model` 값도 낱말 방식으로 더한다(예: 판별 모델 버전 ID, 음성 모델 ID). 화면에서 새 모델을 등록하면 그 모델 이름도 금지어가 된다.
