# 화면 변경 기록

## 2026-10-18 · 검색 최종 평가 표시와 val 실행 분리

- 검색 고정 비교 표의 기본 분할을 test로 바꾸고, 최종 평가 분할이며 설정 고정 커밋 `89eca24`에서 한 번 실행했다는 출처를 표시한다. 판정·해석 문구는 추가하지 않는다.
- 화면 실행은 별도 `val 실행 결과` 영역에서 같은 구성의 val 기준 행과 비교한다. 완료된 val 실행이 없으면 빈 상태만 표시한다. 비용 산정은 기존 val 측정치를 유지한다.
- HTTP·작업 제출·실제 처리에서 test·check를 거부하는 회귀 검사를 둔다. 실제 처리는 원문이나 외부 클라이언트를 만들기 전에 분할을 검사한다.
- `scripts/ui_check.py`로 `admin-models`, `admin-retrieval-confirm`, `admin-models-simulated-val`을 두 폭에서 촬영한다. 마지막 화면은 임시 폴더의 가상 실행 자료이며 실제 성능 측정치가 아니다. 촬영·접근성·키보드 결과는 [스크린샷 기록](screens/changes.md)에 남긴다.
- 고정 결과는 구성별 JSON에서 읽으므로 아직 없는 `claim-check.json`과 후속 갱신될 `report.json`은 화면 표시의 선행 조건이 아니다.
