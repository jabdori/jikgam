## 지적(원문)

1. [중간] [2] 머리글 부제 "010-****-0016 · 월 구독 9,900원 · 결제일 문의 → 해지" — 금액은 오른쪽 고객 정보와, 요청 흐름은 목록 행·요청 변경 줄과 겹친다. — 부제에는 전화번호만 두거나 지금 요청만 적는다.
2. [낮음] [2][3] 목록 행의 "AI 응대 중" 배지 — 세 행이 모두 같아 구분 정보가 없고, 같은 내용이 목록 제목 아래, 메뉴 숫자, 머리글 상태에도 있다. — 기본 상태는 배지를 빼고 운영팀이 움직여야 하는 상태만 배지로 보인다.
3. [낮음] [1] "확인 전 고객" 두 행 — 제목이 같아 주제와 시간으로만 구별된다. — 본인 확인 전에도 알 수 있는 구분자를 함께 보인다.
4. [중간] [기타: 개인정보] 대화 본문의 전화번호와 인증번호 — 머리글은 번호를 가리는데 대화에는 그대로 나온다(시안도 같다). — 대화에도 같은 가림 규칙을 쓰고 인증번호는 대신하는 문구로 바꾼다.
5. [낮음] [1] "고객이 말을 끊음" — 문장이 끝까지 적힌 뒤 붙어 고객이 어디까지 들었는지 알 수 없다. — 듣지 못한 부분을 흐리게 하거나 표시를 뺀다.
6. [낮음] [4] 요청 변경 줄 "결제일 문의 대신 해지 안내로 전환" — "문의"와 "안내"의 짝이 안 맞고 통화 기록 화면과 표현이 다르다. — 같은 단어로 맞춘다.
7. [낮음] [1][4] 진행 단계 "기록 조회 / 안내 / 접수" — 무엇을 안내·접수하는지 빠져 있고 "기록 조회"가 메뉴의 "통화 기록"과 헷갈린다. — "해지 안내", "해지 접수"처럼 지금 요청을 붙이고 "구독·결제 조회"로 바꾼다.
8. [낮음] [3][4] 안내 근거 조항 — 태그 모양이라 필터 칩처럼 보이고 문서 이름이 빠졌으며, 지금 말하는 발화의 근거가 구분되지 않는다. — 문서 이름을 넣은 링크 목록으로 둔다(통화 기록과 함께).
9. [낮음] [4] 페이지 제목 "실시간 통화" — 다른 화면 제목보다 작고 같은 화면의 고객 이름보다도 작다. — 크기를 다른 화면의 제목과 맞춘다.
10. [중간] [390] 상단 메뉴 — "지식·정"에서 잘리고 넘침 단서가 없다. — 넘침 단서를 두거나 메뉴를 접는다.
11. [중간] [390] 배치 순서 — 목록, 대화 전체, 단계·정보·근거 순이라 현재 단계를 보려면 대화를 다 지나야 한다. — 좁은 폭에서는 현재 단계를 머리글에 한 줄로 올리고 목록은 접는다.
12. [중간] [390] 요청 변경 줄 — 두 줄로 바뀌며 구분선이 사라져 일반 주석처럼 보인다. — 짧은 문구를 쓰거나 구분선을 따로 둔다.
13. [낮음] [390] 머리글 버튼 — "상담사가 넘겨받기"만 다음 줄로 떨어진다. — 상태 한 줄, 두 버튼은 다음 줄에 같은 너비로 둔다.
14. [낮음] [390][4] 좌우 여백 — 목록은 약 16px, 대화·정보 카드는 약 32px로 맞지 않고, 대화 본문 칸이 약 240px로 좁다. — 여백을 맞추고 좁은 폭에서는 시각을 화자 줄로 옮겨 본문이 전체 폭을 쓰게 한다.

전체 평가(원문 요약): 시안의 구성(목록, 대화, 진행 단계, 고객 정보, 근거, 버튼 두 개, 요청 변경 한 줄)을 지켰고 엔진 내부 정보와 장식은 없으며 높음 수준 지적은 없다. 부제·배지의 반복, 단계·문구의 용어 불일치, 대화 본문의 가림 불일치가 남았고, 390에서는 메뉴 잘림과 진행 단계가 맨 아래로 밀리는 배치가 가장 걸린다.

## 처리

| 지적 | 처리 |
|---|---|
| 1 | 반영. 부제는 전화번호와 지금 요청("지금 요청: 해지")만 둔다. |
| 2 | 반영. 기본 상태(AI 응대 중)는 목록 행에 배지를 달지 않는다. 상담사 연결 요청·상담사 응대 중만 배지로 보인다. |
| 3 | 반영. 이름을 모르면 고객이 말한 번호(가린 것)를 보인다. 번호도 없으면 "확인 전 고객"이다. |
| 4 | 반영. 대화의 전화번호 가운데와 인증번호를 가린다(통화 기록과 같은 함수). |
| 5 | 반영. "고객이 1.7초 듣고 말을 끊음"처럼 고객이 들은 길이를 적는다(음성 재생 기록의 played_ms). 어디까지 들었는지 글자 단위는 알 수 없다. |
| 6 | 반영. 두 화면 모두 "요청 변경: 결제일 문의 → 해지"로 맞췄다. |
| 7 | 반영. "구독·결제 조회", "해지 안내", "해지 접수"처럼 지금 요청을 붙인다. |
| 8 | 반영. 근거를 "이용약관 제7조 · 월 구독의 해지" 링크 목록으로 바꾸고, 지금 나가는 답의 근거를 맨 위에 둔다. 각 AI 줄 아래에도 근거 조항을 작게 붙였다. |
| 9 | 반영. 목록 제목 크기를 다른 화면의 제목과 같은 토큰으로 맞췄다. |
| 10 | 반영. 좁은 화면 메뉴를 줄바꿈으로 모두 보인다. |
| 11 | 반영. 머리글 상태 배지에 지금 단계("해지 안내")를 붙여 좁은 화면에서도 맨 위에 보인다. 목록은 세 줄이라 접지 않았다. |
| 12 | 반영. 문구를 짧게 바꿔(6번) 한 줄에 들어간다. |
| 13 | 반영. 좁은 화면에서 머리글 버튼이 같은 줄에서 나눠 넓힌다. |
| 14 | 반영. 좁은 화면 여백과 목록 칸 여백을 맞추고, 시간을 화자 줄로 올려 본문이 전체 폭을 쓴다. |
