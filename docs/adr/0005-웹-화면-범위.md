# 0005. 웹 화면은 세 개로 한정한다

- 상태: 채택
- 날짜: 2026-10-12
- 관련: `docs/design.md` §4, §12

## 맥락

화면은 기능을 보여주는 수단이지 이 프로젝트의 검증 대상이 아니다. 화면이 늘면 엔진과 평가에 쓸 시간이 줄어든다.

## 결정

상담 콘솔, 턴 상세 타임라인, 평가 대시보드 세 개만 만든다.

## 근거

세 화면이면 상담사 보조(근거, 확률, 무효화 표시), 단계별 지연 관찰, 모델·정책 비교를 모두 보여줄 수 있다.

## 예상되는 결과

관리 화면, 설정 화면, 로그인은 만들지 않는다. 조직 설정은 파일로 바꾼다.
