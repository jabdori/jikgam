# 0028. v2 엔드투엔드 결과

> 처음 읽는다면: [전체 흐름 안내](../overview.md) · [용어집](../glossary.md)

- 상태: 채택
- 날짜: 2026-10-18
- 관련: `docs/evaluation-v2.md` §8.4, ADR 0025, 0026, 0027

## 맥락

### 어떻게 시작했나

ADR 0026을 보고한 뒤 사용자는 "내가 개입이 필요한 경우가 아닌 이상 멈추지 말고 끝까지 책임지고 진행해"라고 지시했다.

코디네이터는 이 지시를 다음 할 일까지 이어 가라는 뜻으로 해석했다. 다음 할 일은 ADR 0025에서 '다음 일'로 남긴 엔드투엔드였다. 엔드투엔드를 시작하라는 직접 지시는 없었다.

그 뒤 코디네이터가 정한 것은 다음과 같다. 모두 사용자 확인 없이 정했다.
- 판정 도구
- 엔진의 법령 검색어 변경
- 미공개 시나리오 기대값 대조
- 계산 정의
- 설정 고정(ADR 0027)
- 실행

실행이 끝난 뒤 사용자가 새 작업을 멈추게 했다. 보고를 받은 뒤에는 판정까지 끝내기로 결정했다(2026-10-18).

### 실행

- 고정 커밋 `728a02f`의 수정 없는 작업 사본에서 19:16~20:35에 돌렸다. R0 36세션을 먼저, R4 36세션을 이어서 돌렸고, 둘 다 종료 코드 0이다.
- 실행 계약(ADR 0027)은 두 구성 모두 일치했다. 법령 프로필만 다르다.
- 원본 로그는 저장소 밖(`data/v2/local/e2e/`)에 두었다. 저장소에는 표준약관 문장을 가린 공개 사본을 두었고, 고유 조각은 0이다.
- 노출 제안의 주장 판정은 R0를 끝냈다. R4는 일부 하다가 사용자 중단 지시로 멈췄고, 결정 뒤 같은 캐시로 이어서 끝냈다. 미판정 제안은 0이다.

### 사람 확인

사용자가 모델 판정과 구성을 가린 화면에서 확인했다.

| 확인 대상 | 일치 | 일치율 | 묶인 조건 |
|---|---|---|---|
| 주장 근거 | 30개 중 30개(근거 없음 1개도 일치) | 1.00 | 근거 없는 주장 비율 |
| AI가 판정한 시나리오 항목 | 10개 중 8개 | 0.80 | 통과율 |

- 기준은 "0.80 미만이면 판정 보류"다. 두 조건 모두 판정한다.
- 시나리오 항목은 기준선에 걸쳐 있다.
- 어긋난 2개는 모두 AI 판정기가 통과, 사람이 실패로 본 항목이다. AI 판정이 후한 쪽이다.

### 독립 검토

측정과 분리된 검토자(Codex `zai/glm-5.3`)가 비공개 원본, 주장 판정 캐시, 시나리오 기대값에서 §8.4 수치를 직접 다시 계산했다(`results/v2/e2e-review/`).
- 대조 105항목이 모두 일치했고, 네 판정도 같았다.
- 원본 해시 109+109개도 확인했다.
- 문서가 정하지 않아 검토자가 정한 해석은 네 가지다. 모두 보고기와 같은 값을 냈다.
  - 준수 판정의 예외 상태
  - 항목 7·8의 판정 범위
  - 부트스트랩 표본 틀
  - 난수 스트림
- 표본 틀은 유효 실행이 있는 시나리오 11개다. hv01은 두 구성 모두 세 회차가 무효였다.

## 결과(사전 기준 판정)

| 조건(§8.4) | 값 | 기준 | 결과 |
|---|---|---|---|
| 통과율 | R0 16.1%(31개 중 5개), R4 0%(30개 중 0개), R4 − R0 −16.1%p [−36.4, 0] | 점추정 −5%p 이상 | **불만족** |
| "나아졌다" | 위와 같다 | +10%p 이상이고 구간 아래 끝 > 0 | 아니다 |
| 근거 없는 주장 비율 | R0 1.71%(468개 중 8개), R4 1.08%(461개 중 5개), R4 − R0 −0.62%p [−1.59, +0.58] | R4 ≤ R0 | 만족 |
| R4 근거 갱신 p95 | 340.2ms(이벤트 30, 미갱신 0). R0는 303.2ms | 500ms 이하 | 만족 |

**결론:**
- R4는 엔드투엔드 통과율에서 R0보다 16.1%p 낮았다. 그래서 "R4가 상담 결과를 해치지 않는다"고 할 수 없다.
- 근거 없는 주장과 근거 갱신 시간은 기준을 만족했다.
- ADR 0026의 §8.2(리랭킹 지연으로 "낫다" 아님)와 함께 보면, v2 검색 방식이 검색 재현율을 높인 것은 확인했다. 그러나 상담 엔진 안에서 결과가 나아진 것은 확인하지 못했다.

## 결정

1. 판정은 위 표대로 기록한다. 기준(`docs/evaluation-v2.md`)과 고정 설정(ADR 0027)은 바꾸지 않는다.
2. v2 미공개 시나리오 12개는 이번에 썼다. 다시 엔드투엔드를 재려면 새 미공개 시나리오가 필요하다.
3. 엔진의 v2 법령 묶음을 기본값으로 켜지 않는다. 켜는 것은 엔진 설정 변경이므로 사용자 지시가 있을 때 정한다.
4. 새 실험과 새 기능은 멈춘다. PROGRESS의 다음 할 일은 사용자가 지시한 것만 진행한다(2026-10-18 사용자 지시).

## 한계

- AI 고객과 AI 판정기로 잰 합성 결과다. 운영 성과가 아니다.
- 시나리오 12개 × 3회다. hv01은 두 구성 모두 무효라 판정에서 빠졌다.
- 통과율 차이의 95% 구간이 넓다([−36.4, 0]%p).
- 사람 확인의 시나리오 항목 일치율이 기준선(0.80)에 있다. 어긋난 2개는 AI 판정이 후한 쪽이었다.
- 미공개 기대값 8칸은 실행 전에 보관자가 문서 근거로 고쳤다(ADR 0027).
- 엔진의 법령 검색어 변경과 계산 정의는 코디네이터가 사용자 지시 없이 정했다. 실행 전에 ADR로 고정했다.
