# 0011. 판별 백엔드는 Jev, 질문 세트는 q-2026.10.14-mix

- 상태: 채택 (test 평가 전 최종 고정은 §8 절차의 ADR로 따로 남긴다)
- 날짜: 2026-10-14
- 관련: ADR 0007, ADR 0010, `docs/evaluation.md` §2, §7.1, `data/question_sets/`

## 맥락

엔진에 쓸 판별 백엔드와 질문 문구를 val로 골라야 한다. 기준선(`q-2026.10.12`)에서 Jev가 가장 약한 질문은 next_info(54%)와 action(약 80%)이었고, 모든 모델이 라벨 기준 문서에만 있는 규칙(본인 확인 우선, 기록 우선, 절차 조항 기준)을 모르는 상태였다.

## 검토한 대안

val 21건, 판단 152개. 기준선 외에 문구 변형 세 개를 시도했다. 처음 두 변형은 실험 전에 커밋했고, 세 번째는 두 변형의 결과를 보고 만든 뒤 실행 전에 커밋했다.

| 질문 세트 | jev | clef | clef-flash | gemini-flash | 실행 |
|---|---|---|---|---|---|
| `q-2026.10.12` (기준선, 2회 평균) | 89.4% | 87.5% | 73.0% | 91.5% | `20261014T020803`, `20261014T023717` |
| `q-2026.10.14-ko` (라벨 규칙을 문구로) | 88.3% | 86.2% | 65.1% | 93.0% | `20261014T030713` |
| `q-2026.10.14-en` (같은 내용, 영어) | 86.2% | 87.5% | 75.7% | 93.6% | `20261014T031532` |
| `q-2026.10.14-mix` (의미 판단은 기준선, next_info·action만 ko) | 91.6% | 88.8% | 73.7% | 92.5% | `20261014T032548` |

- 라벨 규칙을 문구로 옮기면 gemini-flash는 좋아졌지만 Jev는 나빠졌다. Jev는 우선순위 규칙으로 next_info(54% → 80~94%)와 action(약 80% → 87~89%)이 좋아졌고, 조건이 여러 개인 긴 지시문으로 applies(93.7% → 87~88%)와 sufficient(90% → 75~85%)가 나빠졌다. 영어 문구에서는 Jev의 condition_changed가 62.4%로 떨어졌다. Jev 문서가 밝힌 약점(복잡한 간접 지시, 문자 그대로 읽기)과 맞는 결과다.
- Clef는 모든 변형에서 Jev와 정확도가 비슷하거나 낮았고, 서울에서 Workers AI를 거친 p95 지연이 1.1~2.0초였다.
- Clef-flash는 모든 변형에서 66~76%였다.

## 결정

- 판별 백엔드는 `jev-1.13.0`, 질문 세트는 `q-2026.10.14-mix`다. 엔진 설정의 기본값으로 쓴다.
- 질문 세트는 엔진에서 실제로 쓰는 판별 모델(Jev)의 val 정확도로 골랐다. 주장 1의 test 비교는 사전 고정대로 같은 세트로 `gemini-flash`와 비교한다. 보조 결과로 `gemini-flash`가 val에서 가장 좋았던 `q-2026.10.14-en`으로 낸 test 결과도 함께 보고한다. 비교 대상의 문구를 판별 모델에 맞춰 골랐다는 점을 숨기지 않기 위해서다.
- 엔진은 우선순위 규칙을 코드로 먼저 적용한다(`docs/engine.md` §5). 문구 실험 결과도 같은 방향을 가리킨다. 규칙은 판별 모델의 문구보다 코드에 두는 편이 낫다.

## 근거

- `q-2026.10.14-mix`에서 Jev 91.6%(회차별 136~141개), gemini-flash 92.5%(140~142개), 차이 0.9%p. Jev p95 292ms, gemini-flash p95 4,693ms.
- 모든 val 실행의 원본 로그와 보고서는 `results/decisions/val/`에 있다.

## 예상되는 결과

- mix는 val 결과를 보고 만든 조합이므로 val 수치에는 선택 효과가 섞여 있다. test에서는 더 낮게 나올 수 있다.
- Jev의 ECE는 모든 세트에서 0.12~0.14로 비교 대상 중 가장 높다. 판별 확률을 임계값에 쓰기 전에 val로 보정해야 한다.
- 한국어 튜닝 모델도 같은 질문 세트로 학습·평가한다.
