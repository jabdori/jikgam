# 0031. v2 R5 확정 측정 결과: 근거 단계에서 낫다고 할 수 없고, 근거 없는 주장 조건을 만족하지 못했다

> 처음 읽는다면: [전체 흐름 안내](../overview.md) · [용어집](../glossary.md)

- 상태: 채택
- 날짜: 2026-10-20
- 관련: [evaluation-v2-r5.md](../evaluation-v2-r5.md)(기준), ADR 0027, 0028, 0029, 0030, [v2b-e2e-failures.md](../v2b-e2e-failures.md)

## 맥락

### 실행

- 고정 커밋 `860aec8`(ADR 0030)의 수정 없는 작업 사본에서 돌렸다.
  - R0 72세션: 2026-10-19 20:36~23:06
  - R5 72세션: 23:06~2026-10-20 00:33
  - 둘 다 종료 코드 0이다.
  - 해시·계약 검증을 통과했고, 두 구성의 실행 계약이 일치했다. 법령 프로필만 다르다.
- 원본 로그는 저장소 밖에 두었다. 저장소에는 표준약관 문장을 가린 공개 사본만 있고, 고유 조각은 0이다.
- **AI 시나리오 판정 지연:** 실행 중 판정 응답이 느려져 180초 시간 초과가 여러 번 났다.
  - R0의 세 실행(hw10 3회차, hw15 1회차, hw21 1회차)은 마지막 판정 호출이 시간 초과로 끝났다.
  - 사용자가 결과를 보기 전에 정한 대로(ADR 0030 보완) 두 실행이 끝난 뒤 이 셋만 고정 판정 코드로 다시 판정했다. 셋 모두 판정을 받았다($0.135).
  - R5에는 해당 실행이 없었다.
- 노출 제안의 주장 판정은 R0 408개, R5 410개 제안을 모두 끝냈다. 판정 실패는 0이다.

### 사람 확인

사용자가 모델 판정과 구성을 가린 화면에서 확인했다.

| 확인 대상 | 일치 | 일치율 | 묶인 조건 |
|---|---|---|---|
| 주장 근거 | 30개 중 30개 | 1.00 | 근거 없는 주장 비율 |
| AI가 판정한 시나리오 항목 | 10개 중 9개 | 0.90 | 통과율 |

- 기준은 "0.80 미만이면 판정 보류"다. 두 조건 모두 판정한다.
- 어긋난 1개는 R5 hw03의 항목 9(필수 안내)다. AI 판정기는 통과, 사람은 실패로 봤다. 지난번(ADR 0028)처럼 AI 판정이 후한 쪽이다.
- 표본으로 뽑힌 주장 30개는 AI가 모두 "근거 있음"으로 본 것이었다. 근거 없음 판정에 대한 일치는 이번 확인으로 알 수 없다.

### 독립 검토

- 측정과 분리된 검토자(Claude Sonnet)가 보고기 코드 없이 원본 로그, 주장 판정 기록, 고정 기대값에서 기준 문서의 수치를 다시 계산했다(`results/v2/e2e-review-v2b/`).
  - 대조한 99항목이 모두 일치했고, 네 판정 조건의 결과도 같았다.
  - 비공개 원본 434개의 해시를 확인했다.
  - 법령 덮음 계산은 따로 구현해 세션마다 맞대었고, 어긋난 세션은 0이다.
- 검토자가 정한 해석: 공백 정의, 대체 위치만 있는 항목의 덮음, 같은 제안의 중복 제거, 분모 0 추출 제외(이번에는 0회).
- 검토자가 알려 온 점: R5 근거 갱신 p95는 무효 실행을 넣은 72세션으로 세면 512.8ms로 500ms를 넘는다. 기준은 유효 실행만 집계하므로 판정에는 유효 실행 값을 쓴다.

## 결과(사전 기준 판정)

| 조건(`docs/evaluation-v2-r5.md`) | R0 | R5 | R5 − R0 [95% 구간] | 기준 | 결과 |
|---|---|---|---|---|---|
| **주 지표: 법령 근거 포함률** | 34.8% (89개 중 31개) | 43.7% (87개 중 38개) | +8.8%p [−10.3, +27.1] | +10%p 이상이고 구간 아래 끝 > 0 | **불만족** |
| 통과율 | 5.8% (69개 중 4개) | 18.2% (66개 중 12개) | +12.4%p [+1.5, +25.5] | 점추정 −5%p 이상 | 만족 |
| 근거 없는 주장 비율 | 1.14% (1,057개 중 12개) | 1.40% (998개 중 14개) | +0.27%p [−0.64, +1.13] | 점추정 R5 ≤ R0 | **불만족** |
| R5 근거 갱신 p95 | 253.6ms | 470.7ms(이벤트 66, 미갱신 0) | — | 500ms 이하 | 만족 |

- 구간은 시나리오 24개 단위로 짝지은 부트스트랩이다(10,000회, seed 20261016). 세 지표 모두 쓴 추출이 10,000회다.

**결론:**
- **"R5가 근거 단계에서 낫다"고 할 수 없다.** 법령 근거 포함률은 R5가 8.8%p 높았지만, 사전에 정한 +10%p에 못 미치고 95% 구간에 0이 들어 있다.
- **통과율은 "나빠지지 않았다"를 만족했다.** 통과율 차이의 구간 아래 끝은 0보다 크다. 그러나 이번 기준은 통과율로 "나아졌다"를 판정하지 않기로 실행 전에 정했다(§4). 그래서 통과율 개선을 주장하지 않는다. 두 구성 모두 통과율이 낮다(5.8%, 18.2%).
- **근거 없는 주장 비율은 R5가 R0보다 높아 보호 조건을 만족하지 못했다.** 차이는 0.27%p이고 구간에 0이 들어 있다. 그래도 조건은 점추정이므로 불만족으로 적는다.
- **R5의 근거 갱신 p95는 기준 안이다.** 다만 R0보다 p50이 136ms, p95가 217ms 길다.

## 결정

1. 판정은 위 표대로 기록한다. 기준(`docs/evaluation-v2-r5.md`)과 고정 설정(ADR 0030)은 바꾸지 않는다.
2. v2b 미공개 시나리오 24개는 이번에 썼다. 실패 원인도 들여다봤으므로 다른 확정 측정에 다시 쓰지 않는다.
3. 엔진의 R5 법령 프로필을 기본값으로 켜지 않는다. 조직 A의 `law_profile`은 꺼둔 채로 둔다. 켜는 것은 사용자 지시가 있을 때 정한다.
4. 다음 일은 사용자가 지시한 것만 진행한다.

## 한계

- AI 고객과 AI 판정기로 잰 합성 결과다. 운영 성과가 아니다.
- 시나리오 24개 × 3회다. 구간이 넓다(주 지표 차이 [−10.3, +27.1]%p).
- 시나리오 작성 에이전트에게 R5의 방식(업종과 상담 주제로 거름)이 커밋 제목 한 줄로 노출됐다(ADR 0030).
- 시나리오 작성, 재도출, 대조, 독립 검토를 모두 Claude 계열 모델이 했다.
- AI 판정 호출 오류 세 건은 실행 뒤 다시 판정했다(ADR 0030 보완, 결과를 보기 전 사용자 결정).
- 사람 확인 표본의 주장 30개에 AI가 근거 없음으로 본 주장이 없었다.
- 기준이 유효 실행만 집계해, 무효 실행을 넣으면 R5 근거 갱신 p95가 500ms를 넘는다(512.8ms).
- R5의 주제 판단은 직전 판단의 값이다(한 턴 늦음). 메타데이터 거르기로 빠진 정답 항목 33개가 모두 이 주제 거르기에서 빠졌다. 이 결과로 설정을 바꾸지 않는다.
