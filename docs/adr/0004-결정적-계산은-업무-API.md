# 0004. 금액·자격 같은 결정적 판단은 업무 API가 한다

> 처음 읽는다면: [전체 흐름 안내](../overview.md) · [용어집](../glossary.md)

- 상태: 채택
- 날짜: 2026-10-12
- 관련: `domain/org_a/api.md`, `docs/design.md` §5.4

## 맥락

환불액은 이용 개월 수 올림, 위약금, 10원 미만 절사, 프로모션, 부칙 경과 조치가 함께 걸린다. 생성형 LLM이나 판별 모델이 계산하면 틀릴 수 있고, 틀린 금액은 되돌리기 어렵다. Jev 문서도 날짜 비교와 수 세기가 약점이라고 밝힌다.

## 검토한 대안

- 생성형 LLM이 약관을 읽고 계산한다: 검증할 수 없고 매번 결과가 다를 수 있다.
- 엔진 안에 계산 코드를 둔다: 조직마다 계산 규칙이 달라 엔진 코드가 조직별로 갈라진다.

## 결정

- 금액 계산과 자격 판단은 업무 API의 `quote_refund`가 약관 규칙으로 한다. 모델은 계산하지 않고, API가 준 금액과 근거 조항을 안내한다.
- 날짜 비교, 권한 확인 같은 결정적인 일은 코드로 처리한다.

## 근거

결정적인 일을 코드로 두면 단위 테스트로 검증할 수 있고, 조직별 차이는 업무 API 어댑터에 남는다.

## 예상되는 결과

- 판별 모델은 의미 판단(의도, 조건 변경, 조항 필요성, 충분성, 다음 행동)만 맡는다.
- 업무 API 장애 시 금액을 안내할 수 없으므로 보류 경로가 필요하다(시나리오 s19).
