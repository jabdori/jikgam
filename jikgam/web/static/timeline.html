턴 상세 타임라인

이벤트 로그 하나를 고객 발화(턴)별로 펼친다. 시각은 엔진 단조 시계이며, 턴마다 그 발화의 utterance.end를 0 ms로 둔다.

읽는 법

  • 검색(retrieval.done의 소요 시간)
  • 판별 요청 → 응답
  • 업무 API 호출 → 결과
  • 생성 요청 → 응답
  • 응답 전에 취소된 작업(빗금)
  • 순간 이벤트(근거 갱신, 정책, 제안, 노출, 무효화, 버전 증가, 폐기 등)
  • 조건 변경 표시 발화의 근거 갱신 시간(docs/evaluation.md §3.2)
  • 다음 고객 발화가 도착한 시각

막대 옆 숫자가 같은 정보를 글로 준다. 색은 단계 구분을 돕는 보조 표시다.
