입력 방식

재생 간격은 화면 시연용 값(앞 응답 뒤 1.2초 + 글자당 0.12초, 최대 6초)이며 측정 조건이 아니다. 조건 변경 표시가 붙은 줄은 시나리오 실행기와 같이 직전 고객 발화 1,000ms 뒤에 응답을 기다리지 않고 보낸다(빠른 정정). 재생을 시작하면 모의 업무 API의 상태를 비운다.
